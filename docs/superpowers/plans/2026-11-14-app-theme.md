# The theme colors the whole app Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The one theme setting colors every part of both windows, the title bar buttons and the windows' loading background, with Graphite unchanged color for color.

**Architecture:** `src/shared/themes.ts` (moved from the renderer) derives the app's whole palette from a theme with `appPalette`: Graphite returns today's literal values, any other theme mixes its greys from its background and foreground the way `chatPalette` mixes the chat's today. Both windows set that palette as custom properties on `document.documentElement` at start and on every settings change, so the chat inherits it instead of keeping a scoped copy. `colors.css` holds the same Graphite values as the fallback, and the stylesheets' hard-coded colors become palette properties. Main derives each window's `backgroundColor` and title bar overlay from the same palette (`windowChrome`) when it creates the window and on every theme change.

**Tech Stack:** Electron 44, TypeScript (strict, `noUnusedLocals`, tests type-checked), plain DOM renderer, CSS custom properties, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-14-app-theme-design.md`

## Global Constraints

- Graphite looks exactly as today, color for color. Every value `colors.css` defines today keeps its value. In Graphite the windows' background stays `#0A0A0C` and the title bar overlay stays `{ color: '#0A0A0C', symbolColor: '#B5B5BE' }`.
- One theme setting colors every part of both windows (the main window and the settings window), the title bar buttons and the windows' background while they load. A theme change applies at once, everywhere, without a restart.
- Light or dark comes from the background's luminance, as today: `(r*299 + g*587 + b*114) / 1000 > 128` is light. A light theme gets `color-scheme: light`.
- The palette code lives in `src/shared/themes.ts` and stays pure, because main imports it.
- These colors stay as they are: the non-goals and the colors that no theme changes:
  - the lightbox backdrop `#000d` and the Docs page `.doc-frame` `#fff`;
  - the account badge colors (`src/renderer/account-view.ts` is not touched);
  - shadows, and translucent tints of the accent and of status hues;
  - text drawn on the accent or on group/device colors (`#111`, `#1A1A1A`, `#0A0A0C`, `#FFFFFF`/`#fff`);
  - `.folder-error` `#e06c75`.
  
  The accent is `#D97757` in every theme.
- The setting key `theme` and its values do not change. Only its section title becomes `Theme`.
- Hex values in the palette and in `colors.css` are uppercase, written `#RRGGBB` or `#RRGGBBAA`.

## Review Focus

- **Unreadable colors in a custom theme.** A custom theme object may give its colors in a form other than hex (`rgb()`, names), or lack a background. Every window still gets the full palette and the chrome, with Graphite's values standing in, and never `NaN` or a missing token. Tests: Task 1 and Task 9.
- **A hand edit of `settings.json`.** A theme changed through the file watcher instead of the Settings window reaches both windows at once. Test: Task 6.
- **A theme name that is not built in** (`"Solarized"`). The whole app is Graphite, title bar buttons included. Test: Task 9.
- **A Settings window and a theme change.** A Settings window opened after a theme change has the theme's background from its first frame, and an open one follows a later change. Test: Task 9.
- **Native controls in a light theme.** Scrollbars, `<select>`, and the Recent sessions and folder dialogs, which declared their own dark scheme, are light. Tests: Task 4 and Task 6.

/** colors.css's declarations, an alias (var(--x)) read as the colour it names */
function colorsCss(): Record<string, string> {
  const css = readFileSync(new URL('../../src/renderer/colors.css', import.meta.url), 'utf8')
  const raw = new Map([...css.matchAll(/^\s*(--[\w-]+|color-scheme):\s*([^;]+);/gm)].map((m) => [m[1]!, m[2]!.trim()] as const))
  return Object.fromEntries([...raw].map(([name, value]) => {
    const alias = /^var\((--[\w-]+)\)$/.exec(value)?.[1]
    return [name, alias === undefined ? value : raw.get(alias) ?? value]
  }))
}

function surface(page: Page, selector: string): Promise<string> {
  return page.locator(selector).first().evaluate((el) => {

    return ''
  })

/** the relative luminance of a computed rgb() or rgba() colour, its alpha left out: 0 is black, 1 is white */
function luminance(css: string): number {
  const [r = 0, g = 0, b = 0] = (css.match(/[\d.]+/g) ?? []).slice(0, 3).map(Number).map((c) => {
    const s = c / 255
    return s <= 0.03928 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4
  })
  return 0.2126 * r + 0.7152 * g + 0.0722 * b
}
